User-selected direction: Experimental design museum. User clarified that the existing Port. repository and Pages site must become the learning platform, fully replacing the portfolio app. Do not create a new repository.

Numbered specimens, admission-ticket learning entry, sharp edges, optical mathematical sculptures and generous negative space. Distinct content hierarchy instead of a SaaS dashboard.

Implementation: replace shared navigation, home composition, class presentation, SVG art and CSS. Keep curricular content and saved-progress keys stable. Use self-hosted, subset WOFF2 fonts with licenses. Preserve accessible mobile navigation and reduced-motion behavior. Test the new visuals at 360/390/768/1440px and run existing lesson/regression suites.

Publication: replace the old portfolio source in jayden-ff/Port. using a regular commit, replace gh-pages output with this static build, and verify the deployed https://jayden-ff.github.io/Port./. Do not force-push or rewrite history. Remove the former portfolio application and assets from active source/deployment.

## Final visual steering

The user supplied a dark museum dashboard sketch during implementation. The final design follows its charcoal/lavender palette, sculptural hero image, sidebar, progress bar, current-lesson card and exhibit column. The earlier warm-paper/vermilion exploration was superseded. Mobile rearranges the panels into a single reading flow and keeps the current lesson action visible near the top. The layered marble head is original generated artwork optimized to transparent WebP.
